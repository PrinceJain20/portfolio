SmartMet AI — Packaged Commodities Compliance Inspection System

Problem Statement: Software System to check compliance of Packaged Commodities under Legal Metrology (Packaged Commodities) Rules, 2011 by scanning products, images and labels. (Theme: Agriculture, FoodTech & Rural Development).

Proposed Solution & Core Capabilities:

1. Automated Label Scanning: Automatically scans product labels using smartphone camera or image upload for instant digital inspection.
2. OCR & Declaration Detection: Extracts text via OCR (Tesseract.js / OpenCV.js) to identify mandatory declarations (MRP, Net Quantity, Manufacturer details, Consumer Care).
3. Compliance Rule Engine: Compares extracted data against Legal Metrology Rules, 2011 and BIS guidelines using a TypeScript JSON rule engine.
4. Violation Detection: Flags missing, obscured, or non-compliant information directly on the product label with visual highlights.
5. Evidence-Backed Reporting: Connects highlighted violations directly with product images to generate tamper-proof PDF inspection reports (jsPDF).
6. Centralized Inspection Dashboard: Stores previous inspection records, displays compliance trends, and provides enforcement analytics for regulatory officers.

Technical Approach & Tech Stack:

  • Website Frontend: React, JavaScript, Tailwind CSS (Prince's lead development role)
  • Backend & Storage: Supabase, PostgreSQL Edge Functions, Row Level Security
  • OCR & Computer Vision: Tesseract.js, OpenCV.js
  • AI / ML: TensorFlow, ONNX Web Runtime
  • Reporting: jsPDF, JWT, Digital Evidence Store
